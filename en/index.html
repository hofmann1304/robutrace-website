What works today ↗

From inspection task to system choice

Compare earlier.
Build with purpose.

Machine vision performance depends on the interaction between the part, image acquisition and processing. RobuTrace aims to make those relationships easier to investigate before unsuitable combinations lead to extra purchases, modifications and trials.

01

Describe the inspection task

Define the feature, field of view, cycle time and acquisition conditions. Make missing information and assumptions visible.

02

Investigate system variants

Consider camera, optics, lighting and pipeline together. Today through technical preselection; in future through coupled virtual inspection scenarios.

03

Verify with real images

Test promising variants using real captures. Document results and limitations, then use them to improve the scenario model.

A concrete example

Detect a missing tab.
Under which conditions?

An illustrative inspection task, not a customer project: a missing tab on a part needs to be detected. Which imaging chain and processing approach are suitable?

01

The task

Part position, the smallest relevant feature, field of view and available installation space must be considered together.

02

The variants

Camera resolution, lens and lighting arrangement affect acquisition. The software pipeline must reliably extract the relevant feature from those images.

03

The decision

Which combination should proceed to a real setup? Which assumptions and boundary cases need checking first?

Target workflow: compare the same task virtually across hardware and pipeline variants. The required coupled image simulation has not yet been implemented.

What is possible today

A prototype to build on.
A clear next step.

Existing capabilities and product goals are stated separately so that a development pilot can be scoped realistically.

Available

In the engineering prototype today

  • Capture inspection tasks and structured engineering inputs
  • Preselect camera and hardware candidates using manufacturer data and technical constraints
  • Create pipeline proposals and rule-based variant assessments
  • Manage original images and run simple brightness/area checks locally
  • Explore threshold sensitivity, evaluate imported measurement data and export project reports
In development

The next development step

  • Couple inspection scenarios with virtual image formation
  • Compare hardware variants and executable pipelines within the same scenario
  • Check model predictions against real captures

A validated physical image simulation, complete variant evaluation and industrial prediction accuracy are not yet available. The local image pilot does not provide industrial approval. Validation and traceability remain supporting capabilities.

Before we talk

Can I buy RobuTrace as a finished simulation product?

An engineering prototype is available. Coupled scenario and image simulation is in development. We are currently looking for suitable development partners for a scoped pilot.

Does RobuTrace replace HALCON or OpenCV?

RobuTrace aims to support joint system design and complement existing vision workflows. Production-ready vendor adapters and end-to-end execution of arbitrary pipelines are not yet available.

What do you need for an initial conversation?

A short description of the part, inspection feature and current problem is enough. Approved example images and engineering inputs may help later. Please discuss confidentiality with us before sharing sensitive data.

Do my images stay local?

The current prototype processes its original-image pilot locally. An optional AI analysis sends explicitly confirmed content to an external service. Data access, confidentiality and processing within a development pilot are agreed in advance.
