This website is provided through GitHub Pages. The providers are GitHub B.V., Prins Bernhardplein 200, 1097 JB Amsterdam, the Netherlands, and GitHub, Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, USA.

When the website is accessed, GitHub processes technically required connection data. The processing is necessary to provide the website securely and reliably and is based on Article 6(1)(f) GDPR. The legitimate interest is the secure, stable and economical provision of this online service. Information about GitHub's processing is available in the GitHub General Privacy Statement .

Processing in the USA cannot be ruled out. GitHub describes, among other safeguards, its use of the EU-US Data Privacy Framework and additional protections for international data transfers.
